# NEXUS Learning OS — Final Functional Build

เวอร์ชันนี้เป็นงานรวมที่เน้นให้ปุ่มและ workflow หลักทำงานครบในตัวเอง โดยไม่ต้องติดตั้ง package เพิ่ม

## ใช้งาน
เปิด `index.html` ด้วย browser ได้เลย  
หรือใช้ VS Code Live Server ก็ได้

## ฟังก์ชันที่ทำงานจริง
- TH / EN switch
- Navigation ทุกหน้า
- Search across 44 sessions
- Track filters
- เปิด Session 1–44
- Lesson tabs: Concept / Visual / Example / Lab / Quiz / Recap
- Study / Exam mode
- Focus mode
- Previous / Next
- Complete session + auto XP/level/badge/progress
- Quiz scoring + quiz history
- Notes persistence
- Lab observation persistence
- Project checklist persistence
- Skill progress page
- Export progress JSON
- Reset progress
- Built-in curriculum-aware Study Assistant (offline, no API key required)
- LocalStorage persistence
- Responsive layout

## หมายเหตุ
AI Assistant ในเวอร์ชันนี้เป็น built-in curriculum-aware assistant แบบ offline เพื่อให้ใช้งานได้ทันทีโดยไม่ต้องใส่ API key หรือมี backend
